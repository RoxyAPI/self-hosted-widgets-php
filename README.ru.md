# Виджеты RoxyAPI с вашего собственного домена (PHP)

Один PHP-файл, и виджеты RoxyAPI работают целиком с вашего сайта: сам виджет, поиск города и каждый расчёт загружаются с вашего домена, поэтому посетителю не нужно ждать ответа другого сервера.

[English version](https://github.com/RoxyAPI/self-hosted-widgets-php/blob/main/README.md)

![Натальная карта, нарисованная виджетом RoxyAPI на странице магазина; все файлы отдаёт сам магазин](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/docs/images/10-widget-chart.png)

Скопируйте один файл, вставьте один ключ, вставьте один фрагмент кода. Без плагинов, без базы данных, без настройки сервера и без сборки. Новые виджеты и новые версии виджетов приходят сами.

## Что понадобится

- Сайт на PHP 7.4 или новее. Подойдёт любой хостинг или сервер.
- Тариф RoxyAPI. Тарифы на [странице цен](https://roxyapi.com/pricing).
- Доступ к файлам сайта: файловый менеджер в панели хостинга или SFTP.

## Установка за пять шагов

### 1. Создайте публикуемый ключ для своего сайта

Откройте [API-ключи в аккаунте](https://roxyapi.com/account?tab=keys) и нажмите **New key**. Выберите **Publishable** и **Live**. В поле **Allowed origins** впишите свой домен, а второй строкой тот же домен с `www.` в начале. Нажмите **Create key** и скопируйте ключ, который начинается с `pk_`.

![Окно нового ключа: выбран Publishable, домен сайта в Allowed origins](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/docs/images/00-new-key.png)

Публикуемый ключ отвечает только для перечисленных доменов, поэтому его можно хранить в файле на сайте.

### 2. Скачайте roxy.php и вставьте ключ

Откройте [roxy.php](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/roxy.php) и сохраните страницу как `roxy.php` (Ctrl+S, на Mac Cmd+S). Откройте файл в любом текстовом редакторе. В строке, которая начинается с `$ROXY_KEY`, вставьте ключ между двумя кавычками и сохраните файл.

![Публикуемый ключ вставлен между кавычками в строке ROXY_KEY, файл сохраняется](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/docs/images/03-paste-key.png)

### 3. Загрузите его в корень сайта

Откройте файловый менеджер в панели хостинга и перейдите в папку сайта, ту, где лежит `index.php`. Обычно она называется `public_html`, `www`, `htdocs` или `httpdocs` либо носит имя вашего домена. Загрузите `roxy.php` туда, рядом с `index.php`. По SFTP это та же папка.

![Загрузка roxy.php рядом с index.php в файловом менеджере хостинга](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/docs/images/01-upload.png)

Это вся установка. Ничего не нужно регистрировать и ничего не нужно настраивать на сервере.

### 4. Откройте страницу проверки

Откройте в браузере `https://ваш-сайт.ru/roxy.php?check`, подставив свой домен. Все строки должны быть зелёными. При первом открытии страница проверки также скачивает файлы виджетов в папку `roxy` рядом с `roxy.php`.

![Страница проверки: все строки зелёные](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/docs/images/04-check-green.png)

Под красной строкой написано, что исправить. Если вместо списка вы видите код, который начинается с `<?php`, прочитайте раздел [Вместо страницы проверки виден код](#вместо-страницы-проверки-виден-код).

### 5. Вставьте фрагмент кода на страницу

Вставьте эти три строки туда, где сайт принимает HTML: в редактор страницы в режиме HTML или в шаблон темы. Пошаговые инструкции для популярных конструкторов сайтов и платформ интернет-магазинов есть в [документации RoxyAPI](https://roxyapi.com/docs/widgets).

```html
<script src="/roxy/cdn/roxy-ui.js" defer></script>
<script src="/roxy/cdn/locales/ru.js" defer></script>
<roxy-natal-chart data-endpoint="astrology/natal-chart" submit-url="/roxy.php" location-url="/roxy.php" hide-sections="hint"></roxy-natal-chart>
```

Откройте страницу. Посетитель вводит дату, время и город рождения, выбирает город из списка, и появляется карта.

![Поиск города на странице предлагает подходящие города](https://raw.githubusercontent.com/RoxyAPI/self-hosted-widgets-php/main/docs/images/09-widget-city-search.png)

## Как добавить другие виджеты

С этим файлом работает любой виджет из [галереи виджетов](https://roxyapi.com/widgets). Скопируйте его тег и замените в нём `publishable-key="pk_live_YOUR_KEY"` на `submit-url="/roxy.php" location-url="/roxy.php"`. Две строки `<script>` ставятся на страницу один раз, сколько бы виджетов на ней ни было. Таблица транзитов рядом с картой:

```html
<roxy-transits-table data-endpoint="astrology/transits" submit-url="/roxy.php" location-url="/roxy.php" hide-sections="hint"></roxy-transits-table>
```

Новые виджеты и новые расчёты не требуют никаких изменений в `roxy.php`.

## Какие есть языки

Виджеты говорят на языке страницы. Вторая строка `<script>` подключает русские подписи; замените `ru` на `de`, `es`, `fr`, `hi`, `pt` или `tr` либо уберите строку для английского. Чтобы закрепить язык независимо от страницы, добавьте в тег виджета `lang="ru"`.

## Если что-то не работает

### Поиск города ничего не находит

Откройте `roxy.php?check` и исправьте красные строки. Красная строка **Публикуемый ключ работает для этого сайта** значит, что ключ скопирован не полностью или вашего домена нет в его **Allowed origins**: добавьте и домен, и вариант с `www.`. Если все строки зелёные, проверьте, что страница и `roxy.php` на одном домене и что пути во фрагменте начинаются с `/roxy.php`.

### Виджет совсем не появляется

Откройте в браузере `https://ваш-сайт.ru/roxy/cdn/roxy-ui.js`. Если файл не найден, откройте один раз `roxy.php?check`, он скачает файлы виджетов, и убедитесь, что последняя строка зелёная.

### Виджеты на английском

Оставьте во фрагменте строку с `ru.js` и укажите русский язык страницы либо добавьте в тег виджета `lang="ru"`.

### Красная строка на странице проверки

Под каждой красной строкой написано, что сделать. Красная строка **Сервер связывается с roxyapi.com** значит, что хостинг запрещает исходящие соединения; попросите поддержку хостинга разрешить исходящие HTTPS-соединения. Красная строка **Папка для файлов виджетов доступна для записи** значит, что PHP не может создать папку `roxy`; поставьте для папки сайта права 755 в файловом менеджере.

### Сайт открывается из подпапки

Положите `roxy.php` в эту подпапку и добавьте её во все пути фрагмента: для сайта по адресу `ваш-сайт.ru/shop/` пишите `/shop/roxy/cdn/roxy-ui.js`, `/shop/roxy/cdn/locales/ru.js` и `/shop/roxy.php`.

### Вместо страницы проверки виден код

Ваш сервер запускает только свой главный PHP-файл, а остальные PHP-файлы показывает как текст. Попросите поддержку хостинга или разработчика разрешить запуск `roxy.php` так же, как `index.php`. Для nginx это один блок location рядом с блоком, который обслуживает `index.php`:

```nginx
location = /roxy.php {
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root/roxy.php;
    fastcgi_pass 127.0.0.1:9000;
}
```

Значение `fastcgi_pass` возьмите такое же, как в блоке для `index.php`, затем снова откройте страницу проверки.

## Как приходят обновления

Сами. Каждые несколько часов `roxy.php` проверяет, вышла ли новая версия виджетов, и если вышла, скачивает её в папку `roxy`. Страница проверки показывает текущую версию. Обновлять вручную ничего не нужно.

## Как удалить

Уберите фрагмент кода со страниц, затем удалите с сервера `roxy.php` и папку `roxy`.
